# MineUX's visual modules (full edition only), read after core's own settings tree: registered
# with Extensions.addModuleFile("/mineux/visuals.txt") by com.mineux.visuals.Visuals.
#
# The same format as core's own module file:
#
#   dir <path> cfg=<binding> [toggle=<field>] | <description>
#   set <key> <field> [alias=a,b] [label=a_b] [min=<n>] [max=<n>] [pair=<field>] [choices=a;b] [key] | <description>
#
# A dir's parent is its path minus the last part; settings belong to the dir above them. cfg
# names a config registered with Extensions.addConfig (com.mineux.visuals.VisualConfigs), which
# makes it per workstation. In choices and label, '_' stands for a space. key marks a keybind.
# fold opens a settings window's rows with its switch; stat names a line under them that says what
# the module last did; act a button row (the skin changer's browse files). advanced puts a
# setting under the module's closed "advanced" section. vulkan=no marks something that needs
# OpenGL; every visual here runs on both backends (gpu.Shader), so nothing carries it.
#
# Which tray group each top-level dir sits in: com.mineux.visuals.Visuals (hud, world, camera, self).

dir view cfg=view | the view: zoom, and clear weather
set weather clearWeather alias=noweather,ambience | clear weather: no rain, snow or thunder on your screen; the server's weather goes on

dir view/zoom cfg=view toggle=zoom | zoom: hold the key to look closer; the mouse slows to match, so a movement of it covers the same part of the picture

set factor zoomFactor min=1.5 max=12 | how many times closer
set mode zoomMode choices=instant;smooth_zoom | instant: straight in and straight back out; smooth zoom (default): eased in and out over the time below, the same at any frame rate, with no overshoot
set time zoomTime min=0.05 max=1 | smooth zoom: seconds to go all the way in, or all the way out
